# Nopetion demo assets

- [Campaign film](nopetion-demo.mp4): 1920 × 1080, 60 fps, 54 seconds, with English instructions, action-focused camera zooms, click highlights and animated typography.
- [Preview image](nopetion-preview.jpg): actual application captures composed for the main README.

**Your docs. Your server. Your peace of mind.** The introduction and closing scene use animated document/server graphics to present a personal, self-hosted workspace.

The video reuses real browser interactions recorded on 2026-10-18 in a dedicated demo workspace on a running Nopetion server, with a new campaign treatment created on 2026-10-19. Example documents were prepared for the recording. Account identity is covered, and browser chrome, server addresses and credentials are excluded from the frame. The underlying application interface is Korean; the campaign headlines and instructions are English.

The sequence shows writing, a checklist update, emoji selection, creation of a nested page, search, the document AI panel and a successful PDF download with selected descendants. AI account connection and content scope are introduced; AI generation is not demonstrated, and no inference request was sent for filming.

Idle save and navigation waits are shortened, and portions play faster. The soundtrack and click/transition accents are original synthesized audio with no third-party recordings.
